# AI祝福工厂

微信AI小程序，30秒生成专属节日祝福文案+精美海报，一键转发微信好友。

## 产品定位
不只写一段祝福语，而是生成一套完整的祝福体验——文案+海报+提醒。

## 核心差异化
- 全节日覆盖：父亲节/端午/七夕/中秋/春节/教师节/母亲节/生日...
- 全表达形式：文案+海报（v1.0）→ 语音（v1.1）→ 视频（v1.2）
- 全风格选择：温情/正式/幽默/文艺/古风/简约
- 内置社交裂变：使用产品=传播产品（生成→发送→收件人好奇→也来用）

## 技术栈
- 微信小程序原生
- 微信云开发
- 腾讯混元大模型（文生文+文生图）
- Canvas 2D海报合成
